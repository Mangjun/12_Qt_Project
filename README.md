# 📅 일정 관리 앱 (Mini Project)

임베디드 환경의 제약 조건을 고려하여 메모리 효율성과 빠른 반응성을 목표로 설계된 C++/Qt 기반 일정 관리 시스템입니다.

---

## 1. 프로젝트 개요
- **진행 기간**: 2026.04.20 ~ 2026.04.22 (3일)
- **참여 인원**: 2명
- **개발 환경**: C++, Qt Framework
- **핵심 목표**: 
  - MVC 및 Repository 패턴을 통한 확장성 확보
  - 싱글톤 및 캐싱을 활용한 성능 최적화
  - 파일 시스템 기반의 효율적인 데이터 관리 (Embedded-friendly)

---

## 2. 시스템 아키텍처 및 설계 특징

### 🏗️ 디자인 패턴 및 구조
- **MVC & Repository 패턴**: UI(Widget), 비즈니스 로직, 데이터 접근 계층을 분리하여 유지보수성을 높였습니다.
- **추상화 기반 데이터 관리**: `DataManager`를 추상 클래스로 정의하여 **휘발성 메모리 저장 방식**과 **로컬 JSON 저장 방식**을 유연하게 교체할 수 있습니다. (추후 서버 통신 모듈 확장 가능)
- **싱글톤 위젯 관리자 (Widget Manager)**: 위젯 간의 전환을 통합 관리하며, 객체 생성 비용을 최소화하기 위해 싱글톤 패턴을 적용했습니다.

### ⚡ 성능 및 안정성 최적화
- **Const correctness**: 모든 멤버 함수에 `const` 한정을 적용하여 데이터 무결성을 보장하고 안정성을 확보했습니다.
- **불필요한 복사 방지**: 객체 전달 시 참조자(`&`)를 적극 활용하여 메모리 오버헤드를 줄이고 반응 속도를 높였습니다.
- **데이터 캐싱 전략**: 위젯 관리자 내부에 `Date`를 키값으로 하는 캐시를 구현하여, 동일 날짜 조회 시 파일 I/O 횟수를 획기적으로 단축했습니다.

---

## 3. 데이터 및 파일 구조 설계

임베디드 환경의 특성을 고려하여 무거운 DB 대신 효율적인 **파일 디렉토리 구조**를 채택했습니다.

### 📂 폴더 및 파일 구조
유저별로 독립된 폴더를 구성하여 데이터 로딩 속도를 최적화했습니다.   
유저가 늘어나도 전체 파일을 읽을 필요가 없어 조회 성능이 우수합니다.
```text
/data
  /meta_user.json (totalCount 및 유저 배열 저장)
  /{user_id_1}
    - meta_schedule.json  (totalCount 및 일정 배열 저장)
  /{user_id_2}
    - meta_schedule.json
```

### 📊 데이터 스키마
| 구분 | 필드 구성 |
| :--- | :--- |
| **User** | `id` (Unique), `userId`, `userPw` |
| **Schedule** | `id` (Unique), `title`, `date`, `detail` |

## 4. 화면 흐름도 (UX/UI)

사용자 편의를 위해 일정이 등록된 날짜를 캘린더에 별도로 표시하여 직관적인 UX를 제공합니다.

1.  **인증**: 로그인 ↔ 회원가입 다이얼로그
2.  **메인**: 캘린더 화면 ➔ 일별 일정 목록 ➔ 일정 상세 화면 / 일정 추가 다이얼로그
3.  **검색**: 제목 검색(캘린더 화면) ➔ 일정 상세 화면 직접 이동

---

## 5. 주요 기능
* **사용자 관리**: 회원가입 및 로그인 기능.
* **일정 관리 (CRUD)**: 일정 등록, 조회, 수정, 삭제 기능.
* **검색**: 제목 기반의 고속 필터링 검색.
* **UX 최적화**: 캘린더 내 일정 유무 표시 및 캐싱을 통한 빠른 화면 전환.

---

## 6. 개발자 코멘트
> **"왜 DB가 아닌 파일 시스템인가?"**
> 
> 실제 임베디드 기기에서는 리소스 제약으로 인해 무거운 DB 엔진을 구동하기 어려운 경우가 많습니다. 본 프로젝트는 이러한 제한적 환경을 가정하여, **메모리 효율성**과 **파일 시스템 최적화**에 초점을 맞췄습니다. 특히 유저 식별자를 폴더 구조로 분할한 설계는 데이터량이 증가해도 조회 성능을 일정하게 유지할 수 있는 핵심 전략입니다.
